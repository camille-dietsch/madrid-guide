# Madrid, comme je l’aime

Guide personnel de Madrid — version française (`index.html`) et anglaise (`en/index.html`).
Chaque page est autonome : textes, photos, pictos, styles et scripts sont dedans. Rien à installer.

## Mettre en ligne avec GitHub Pages

1. Sur github.com, crée un nouveau dépôt (par ex. `madrid`), en **Public**.
2. Clique sur **Add file → Upload files** et glisse **tout le contenu de ce dossier**
   (`index.html`, le dossier `en`, `.nojekyll`, ce `README.md`). Valide avec **Commit changes**.
3. Va dans **Settings → Pages**. Dans « Build and deployment », choisis
   **Source : Deploy from a branch**, **Branch : main**, dossier **/(root)**, puis **Save**.
4. Après une minute ou deux, le site est en ligne à l’adresse
   `https://TON-PSEUDO.github.io/madrid/` (et la version anglaise à `.../madrid/en/`).

Astuce : le fichier `.nojekyll` commence par un point, il peut être masqué sur ton ordinateur.
Il n’est pas indispensable, mais il évite à GitHub de retraiter les fichiers.
